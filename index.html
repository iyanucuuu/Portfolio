League of Legends Profile

Visor de perfiles de League of Legends que consume la API oficial de Riot Games. Muestra estadísticas detalladas de jugadores, historial de partidas y clasificación en la región EUW.

  • Búsqueda de jugadores por Riot ID (nombre#tag)
  • Estadísticas de clasificación y rango actual
  • Historial de partidas con detalles por match
  • Proxy Node.js para resolver CORS con la Riot API
  • Soporte para región EUW (euw1 + europe routing)
Angular 21 TypeScript Node.js Express Riot API REST API

Anime Hub

Plataforma de anime que combina un catálogo completo con gestión de listas personales. Explora y busca series usando la API de Jikan (MyAnimeList) y organiza tu colección en listas personalizadas.

  • Catálogo de anime con búsqueda y filtros por género, temporada y puntuación
  • Ficha detallada de cada serie con sinopsis, episodios y puntuación
  • Gestión de listas personales: visto, en progreso y pendiente
  • Sistema de autenticación para guardar el progreso del usuario
  • Integración con la API pública de Jikan (MyAnimeList)
  • Backend con Node.js/Express para gestión de usuarios y listas
