# Portfolio — Iyán Gironés Suárez

Sitio web personal de presentación profesional. Una página estática de una sola vista (single-page) que muestra quién soy, mi formación, experiencia, tecnologías y proyectos, con un apartado de contacto.

## Sobre mí

Desarrollador Full Stack con experiencia en el ecosistema Angular y Node.js, especializado en transformar ideas en productos digitales con código limpio y bien estructurado. He desarrollado proyectos que van desde aplicaciones de gestión financiera personal con visualización de datos, hasta plataformas sociales con mapas interactivos y sistemas de clanes.

## Secciones

- **Hero** — presentación inicial
- **Sobre mí** — perfil y motivación
- **Formación**
- **Experiencia**
- **Tecnologías**
- **Proyectos**
- **Contacto**

## Stack tecnológico

- HTML, CSS y JavaScript (proyecto estático, todo contenido en `index.html`)

## Puesta en marcha

No requiere instalación ni dependencias. Basta con abrir `index.html` en el navegador, o servir la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```
